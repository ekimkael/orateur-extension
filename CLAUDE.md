# Règles du projet

- Toujours travailler sur `develop` ou une autre branche que `main`. `main` est réservée aux releases : n'y committer ni n'y pousser directement.
- La documentation, les commentaires de code, les messages de commits, de pull requests, les changelogs et les releases doivent être écrits en anglais.
- PDF development, packaging and publication are excluded unless the user explicitly requests PDF. Do not propose PDF work or ask whether to include it by default.
