# Architecture decision records

One file per decision: `NNNN-short-title.md`, numbered in order, never rewritten. A reversed decision gets a new ADR that supersedes the old one.

```markdown
# NNNN. Title

Date: YYYY-MM-DD
Status: accepted | superseded by NNNN

## Context
What forces the decision.

## Options
Each option considered, including "do nothing", with its cost.

## Decision
What we chose and why.

## Consequences
What becomes easier, what becomes harder.
```
